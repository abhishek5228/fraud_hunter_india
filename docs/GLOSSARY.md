# Glossary

Plain-language meanings of the words used in this project.

| Term | Meaning |
|---|---|
| **UPI** | India's instant payment system. Phone-to-phone or phone-to-shop, in seconds. |
| **IMPS / NEFT** | Bank-to-bank transfers. IMPS is instant and carries the large transfers. |
| **Rail** | The payment channel: UPI, IMPS, card in person (`pos`), card online (`ecom`), ATM. |
| **Approve / Step-up / Decline** | The three answers. Step-up asks the customer to prove it is them (OTP or in-app confirmation). |
| **Mule account** | A rented bank account that only receives stolen money and passes it on. |
| **Fan-in** | Many different people paying the same account. A mule shows up as many *first-time* senders. |
| **Vishing** | Voice phishing: a caller pretends to be a bank or officer and talks the customer into paying. |
| **Screen-share scam** | The scammer makes the victim install a remote-access app (AnyDesk, TeamViewer) and watches or controls the phone. |
| **SIM swap** | A fraudster moves the victim's phone number to a new SIM, then re-binds UPI on a new phone. |
| **Collect request** | A UPI request that *takes* money when approved. Approving one sends money out. |
| **Structuring** | Keeping amounts just under a limit (for example Rs 49,500 under Rs 50,000) to avoid checks. |
| **Authorised scam** | The customer is tricked into paying. It taints the payee, not the victim's own phone. |
| **Guardrail rule** | A hard rule that can only make the answer stricter, never more lenient. |
| **Log-odds / contribution** | The model adds up per-feature numbers. Each feature's share of the total is its contribution. |
| **GAM** | Generalized additive model: a sum of one curve per feature, so each feature's effect can be read directly. |
| **AUC / average precision** | Scores of how well the model ranks fraud above honest payments. |
| **Calibration (ECE)** | When the model says 20%, is it right about 20% of the time? |
| **PSI (drift)** | Population stability index: how much recent traffic differs from what the model was trained on. |
| **Red team** | An automated attacker that searches for the strategy that slips past the engine. |
| **PSI (set intersection)** | Private set intersection: two banks find which payees they both flagged without revealing the rest. Not the same as the drift PSI above. |
| **STR** | Suspicious transaction report, filed by banks with India's Financial Intelligence Unit. |
| **1930** | India's national cyber-fraud helpline; reports can also be filed at cybercrime.gov.in. |
| **Synthetic data** | Data generated by a simulator. Nothing here comes from real customers. |
